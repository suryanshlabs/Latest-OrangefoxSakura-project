# proprietary-files.txt — recovery-only QTI TEE / crypto blobs for sakura
#
# WHAT THIS FILE IS
# -----------------
# A manifest consumed by two scripts:
#
#   build/extract_blobs.sh   reads a stock vendor.img, validates and copies
#                            exactly these files into vendor_blobs/ (gitignored)
#                            and writes a local checksum + provenance report.
#   build/install_blobs.sh   copies the validated vendor_blobs/ set into
#                            device/xiaomi/sakura/recovery/root/ and generates
#                            blob_install.mk so the build packs them.
#
# FORMAT
#   <path inside vendor.img>:<path relative to the recovery ramdisk>|<required|optional>|[sha256]
#
#   * The source path is relative to the ROOT of vendor.img from a Xiaomi
#     fastboot ROM (vendor.img root == the device's /vendor). "/" and a
#     "vendor/" prefix are also accepted for tolerance.
#   * The destination is relative to the recovery ramdisk, and MUST equal the
#     executable path used by the init service in
#     recovery/root/init.recovery.qcom_decrypt.rc. tools/check_init_services.py
#     enforces that equality; it is not a convention, it is a build gate.
#   * "required" means the file must exist in the supplied firmware; a missing
#     required entry aborts extraction. "optional" entries are extracted and
#     hashed when present, and skipped when the firmware does not ship them —
#     but if the TEE chain actually links against one, the DT_NEEDED resolution
#     check still fails the build. Optional is not a way to hide a dependency.
#   * The sha256 column is "-" until extraction records the real value. Hashes
#     are recorded in vendor_blobs/EXTRACTION_REPORT.md and
#     vendor_blobs/MANIFEST.sha256, which are LOCAL ONLY. Never invent a hash.
#
# WHY THIS IS 64-BIT ONLY
# -----------------------
# The recovery ramdisk is built from core_64_bit_only.mk; tools/elf.py rejects
# anything that is not ELFCLASS64/EM_AARCH64 before it can be installed.
#
# PROVENANCE — READ BEFORE BUILDING
# ---------------------------------
# The community tree these paths were first taken from
# (msm8953E/device_xiaomi_sakura_twrp @ ofx-12.1) states its blobs come from
#     daisy-user 10 QKQ1.191002.002 V11.0.21.0.QDLMIXM release-keys
# i.e. Mi A2 Lite (daisy), NOT sakura. They are not redistributed here and are
# NOT verified for sakura. Extract your own from a sakura Android 9 fastboot
# ROM (V12.0.4.0.PDMMIXM Global or V12.0.1.0.PDICNXM China); the extraction
# report records the firmware file, its SHA-256, the vendor.img SHA-256 and the
# vendor build fingerprint so the provenance of a given build is auditable.
#
# These are Xiaomi/Qualcomm proprietary binaries. This repository does not
# contain them and never will. See documentation/DEPENDENCIES.md section 4.
